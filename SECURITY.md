# Security Policy

Trusted Links changes how external URLs are confirmed, so hostname-validation issues are treated as security-sensitive.

## Supported versions

Only the latest published release for Minecraft 26.1.2 is currently supported.

## Reporting a vulnerability

Please report suspected bypasses privately through GitHub's **Report a vulnerability** feature once the repository is published. Do not include exploitable URLs in a public issue.

A useful report includes the URL shape, the trusted configuration entry, the observed result, the expected result, and the mod version. Avoid visiting or linking to harmful content while preparing a report.

Until a public security contact is configured, keep the details private and contact the repository owner directly.
